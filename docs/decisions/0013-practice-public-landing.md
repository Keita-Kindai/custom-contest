# ADR-0013: 精進側の公開LPをトップページに置く

- Status: Accepted
- Date: 2026-09-15
- Owners: User / Codex

## Context

最初の公開対象はDiscover・問題セット作成・ライブラリで、AC Duelは公開しない（ADR-0010）。現在のトップページは対戦デモで、配備時にDiscoverへ転送している。初回訪問者には、問題セットを探す・作るという用途と次の操作を短く説明する入口が要る。Userは2026-09-15にLPの主導線を「問題セットを探す・作る」と決めた。

## Decision drivers

- 匿名訪問者がログイン前に用途を理解できる
- Discoverと問題セット作成へ1操作で進める
- 対戦画面・APIの公開停止を保つ
- 既存の精進skinとモバイル操作を保つ
- 利用実績や未公開機能を誇張しない

## Options

### Option A: トップページをDiscoverへ転送する

既存の動線は短いが、初回訪問者へ用途と作成方法を説明する場所がない。

### Option B: トップページを精進側LPにする

入口で用途と操作を伝え、Discoverと作成へ進める。LPの保守が必要になる。

## Decision

Option Bを採用する。トップページに精進側LPを置き、Discoverと作成を主導線にする。旧対戦トップのcomponentは残すが公開routeから参照しない。対戦画面の転送と対戦APIの機能境界は維持する。LPは現時点で提供できる精進機能だけを説明し、外部問題の追加等は対応する変更が公開されるまで約束しない。

## Consequences

- トップページのDiscover転送を外す
- 認証状態に応じて「作る」は既存のログイン入口へ進む
- LPのページ本文とCSSを精進skin上へ追加する
- 将来AC Duelを公開する際、LP内の導線を別途判断する

## Verification

- トップページが200で表示され、Discover・作成へ遷移できる
- 匿名利用者の作成入口はログインへ進む
- 320 / 375 / 414 / 768 pxで横スクロールと操作不能がない
- 対戦画面と対戦APIの公開停止が残る
- pnpm checkが成功する

## Revisit triggers

- AC Duelを公開する
- 精進以外の機能が主目的になる
- LPからDiscover・作成への移動に大きな離脱がある
