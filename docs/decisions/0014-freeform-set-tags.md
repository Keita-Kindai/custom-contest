# ADR-0014: セットタグの自由入力と公開候補

- Status: Accepted
- Date: 2026-09-15
- Owners: User / Codex

## Context

セット作成画面は12個の固定タグしか選べない。外部問題を含む自由なセットの主題を表しにくく、利用者は公開セットをタグで見つけられない。

## Decision

タグは問題ではなくセットへ付ける。既存の `problem_sets.tags text[]` に最大6個、各1〜24文字の正規化済み文字列を保持する。入力は NFKC 正規化・前後空白除去を行い、制御文字と重複を拒否する。作成画面では既存タグを選べるほか、`+` から任意のタグを追加・解除できる。

公開候補は `visibility = public` かつ `status = published` のセットで実際に使われたタグを出現回数順に最大30件返す。未公開・限定公開・非公開セットのタグは候補へ反映しない。検索APIは任意の検証済みタグを受け付けるが、候補にないタグの総当たり列挙機能は用意しない。

## Alternatives

- 固定タグだけを増やす: セットの用途が増えるたびにデプロイが必要。
- 独立したタグ辞書 table: 編集履歴や所有権が必要になった時点で導入する。現在は属性を持たせない。

## Acceptance criteria

- ログイン済みの作成者が `+` からタグを付け、保存・再編集で保持できる。
- 24文字超、空白だけ、制御文字、重複、7個目は拒否される。
- 公開済みの公開セットで使用されたタグのみ Discover と作成画面の候補に現れる。
- 長いタグはカード上で省略されても詳細画面と入力欄で全文を確認できる。

## Consequences

タグの表記ゆれは NFKC と大文字小文字の比較である程度抑える。候補集計は公開セットが増えたら集計 table / キャッシュへ移す。
