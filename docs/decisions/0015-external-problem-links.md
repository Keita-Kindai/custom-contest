# ADR-0015: 外部問題リンクの共通カタログ

- Status: Accepted
- Date: 2026-09-15
- Owners: User / Codex

## Context

問題セットに追加できるのは固定 JSON の AtCoder 問題だけ。ShareOJ、yukicoder、Codeforces、ICPC やその他の問題を扱い、誰でも独自のセットを組めるようにしたい。ただしサイトごとに API・規約・難易度尺度が異なる。

## Decision

初期版は **ログイン済み利用者による手動の題名 + HTTPS URL 登録**とする。元サイトから問題文を複製せず、アプリのサーバーから登録 URL へのリクエストを一切発生させない。カタログの ID は正規化 URL の SHA-256 で namespaced `ext_` ID にし、同じ URL の登録は既存のエントリを返す。登録エントリは全員が検索・再利用できる。登録者のアカウントが消えても参照中の問題は残る。題名の編集・削除はこの版では提供しない。

AtCoder 固定 JSON は従来どおり高速なメモリー検索を使う。外部登録エントリは明示的に検索したときだけ、上限付き DB 検索を使う。URL は HTTPS、資格情報なし、公開ドメインのみ受け付け、ローカル名・IP アドレスを拒否する。全リンクは `noopener noreferrer` で別タブに開く。

外部サイトの難易度は共通換算しない。セットの作成者が各収録問題に任意の AtCoder 色を付けられる。無選択を既定とし、元カタログの Difficulty とは別の `problem_set_items.author_band` に持つ。値はそのセットだけに属し、同じ問題を使う別セットへ伝播しない。

## Alternatives

- サイトごとの URL 解析・API 連携: 規約、レート制限、キャッシュ、SSRF、可用性の検討が各サイトで必要。手動リンク版の利用状況を見て個別に判断する。
- 問題文の保存: 著作権・更新追従・保存量の懸念が大きい。
- グローバル難易度の上書き: 同じ問題を使う作者間で見解が異なる。

## Acceptance criteria

- ログイン済み作成者が外部 URL と題名を登録し、自分のセットに追加できる。
- 既登録 URL は重複せず、他の利用者が検索・再利用できる。
- 未ログイン登録、HTTP URL、ローカル名、IP、資格情報付き URL は拒否される。
- セット保存は登録済み ID だけを参照し、クライアント送信の題名・リンクで DB の問題を変更しない。
- 任意の色は編集・詳細表示で保持され、別セットへ漏れない。
- 登録リンクへのサーバー側 fetch は存在せず、問題名のクリックで元サイトを開く。

## Consequences

登録者による題名の品質とリンク切れはコミュニティ管理が必要になる。サイト別自動取り込み、報告・訂正・モデレーション、登録の持続的なレート制限は公開前の運用課題として追跡する。
